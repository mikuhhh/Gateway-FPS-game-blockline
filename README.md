爆破具体规则
双方至少各有一人或机器人后开局。准备 5 秒，正式回合 120 秒，回合结束后等待 6 秒进入下一回合。整局结束后 10 秒自动重开。
进攻方随机一人携弹。携弹者进入 A / B 地面圆圈，静止并按住 B 3 秒安放；手机按住“安放/拆除”。无需切换到炸弹武器。
携弹者死亡或离线会掉落炸弹，其他进攻方玩家靠近即可拾取。地面装置和小地图标记显示位置。
安放后倒计时 35 秒，防守方靠近装置 2.5 米内，静止并按住 B 5 秒拆除。松键、移动、跳跃、受伤或死亡会中断并清空进度；开火和换弹期间不能操作。
未安放时，进攻方全灭或时间耗尽，防守方胜；防守方全灭则进攻方胜。安放后进攻方全灭不会终止炸弹计时，防守方仍需要拆弹。
炸弹爆炸为进攻方胜，拆除为防守方胜。每回合恢复生命 100。无场内补给，死亡后等下一回合；中途加入正式回合的玩家也等待下一回合。
死亡时按 Space，或手机点击“观战”，轮换存活队友视角。双方队伍颜色固定，攻守身份交替。
